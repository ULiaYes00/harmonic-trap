# Monte Carlo Thermodynamics of Interacting Particles in a Harmonic Trap

A computational physics study of a classical two-particle system in a three-dimensional harmonic trap with a tunable power-law interaction. The system is treated in the canonical ensemble. All thermodynamic quantities are derived from the configurational partition function $Z(T, L)$, which is estimated by Monte Carlo integration using two approaches: **Crude Monte Carlo (CMC)** and **Importance Sampling (IS)**. The two are compared in accuracy and statistical efficiency across temperatures and interaction parameters.

## Model

The potential energy of a configuration $(\mathbf{x}, \mathbf{y})$ with $\mathbf{x}, \mathbf{y} \in \mathbb{R}^3$ is

$$U(\mathbf{x}, \mathbf{y}) = a\left(\mathbf{x}^2 + \mathbf{y}^2 + \frac{b}{2}\,|\mathbf{x} - \mathbf{y}|^{2+\gamma}\right)$$

The configurational partition function (units $k_B = 1$) is integrated over the cube $[0, L]^6$:

$$Z(T, L) = \int_0^L \!\!\cdots\! \int_0^L e^{-U/T}\, d\mathbf{x}\, d\mathbf{y}$$

| Parameter | Meaning |
|---|---|
| $a$ | trap stiffness |
| $b$ | interaction strength |
| $\gamma$ | interaction exponent (controls the character of binding) |
| $L$ | size of the confinement region, $V \sim L^3$ |

## Thermodynamic quantities

Every quantity follows from $\ln Z$ and its derivatives:

| Quantity | Expression |
|---|---|
| Free energy | $F = -T \ln Z$ |
| Mean energy | $\langle E \rangle = T^2\, \partial \ln Z / \partial T$ |
| Entropy | $S = \ln Z + \langle E \rangle / T$ |
| Heat capacity | $C_V = \partial \langle E \rangle / \partial T = \left(\langle E^2 \rangle - \langle E \rangle^2\right)/T^2$ |
| Pressure | $P = \dfrac{T}{3L^2}\, \dfrac{\partial \ln Z}{\partial L}$ |

The derivative with respect to $L$ is computed by a central finite difference with step $0.01L$, using the same random numbers for $L \pm h$ (common random numbers), which strongly suppresses noise.

## Methods

### Crude Monte Carlo (CMC)

Points are drawn uniformly in $[0, L]^6$:

$$Z \approx L^6 \cdot \frac{1}{N} \sum_{i=1}^{N} e^{-U_i / T}$$

The method is simple, but at low temperatures the main contribution to $Z$ comes from a small region near the trap center that few samples reach. The effective sample size (ESS) collapses.

### Importance Sampling (IS)

Points are drawn from a Gaussian matched to the temperature and trap stiffness, $\sigma^2 = T / (2a)$, truncated to $[0, L]$ and generated by inverse-CDF sampling:

$$Z \approx \frac{1}{N} \sum_{i=1}^{N} \frac{e^{-U_i/T}}{q(\mathbf{x}_i)\, q(\mathbf{y}_i)}$$

The proposal $q$ is normalized on $[0, L]$, so the estimate of $Z$ is unbiased. The proposal captures the trap potential, so the ESS stays close to $N$. The interaction term is not included in the proposal.

All averages are self-normalized weighted means, and the effective sample size is

$$\mathrm{ESS} = \frac{1}{\sum_i w_i^2}, \qquad w_i = \frac{\tilde w_i}{\sum_j \tilde w_j}$$

## Random number generation

Uniform variates come from a custom linear congruential generator (Numba-compiled; $a = 1664525$, $c = 1013904223$, $m = 2^{32}$). All runs consume numbers sequentially from a single stream, so no part of the sequence is reused and the runs are statistically independent.

Two normal-variate generators are also implemented and validated against $N(0, 1)$ with histograms:

- Box–Muller transform;
- rejection sampling.

## Numerical experiment

| Setting | Value |
|---|---|
| Samples per estimate, $N$ | 100,000 |
| Independent runs | 10 |
| Temperatures $T$ | 10 points from 0.5 to 5.0 |
| Region size $L$ | 4.0 |
| Methods | CMC, IS |

### Parameter sets

Each set varies one parameter relative to the baseline:

| Set | $a$ | $b$ | $\gamma$ |
|---|---|---|---|
| Baseline parameters | 1.0 | 0.5 | 1.0 |
| Variation of a | 0.7 | 0.5 | 1.0 |
| Variation of b | 1.0 | 1.0 | 1.0 |
| Variation of gamma | 1.0 | 0.5 | 2.0 |

The baseline set is the reference point. The other sets are compared against it to isolate the effect of each parameter.

## Installation and usage

Requires Python 3.9+.

```bash
pip install numpy scipy pandas matplotlib numba
python thermo_mc.py
```

The full run (4 parameter sets) takes about 40 seconds. Settings are constants at the top of the script:

| Constant | Purpose |
|---|---|
| `N_SAMPLES`, `N_RUNS` | samples per estimate and number of runs |
| `TEMPERATURES` | temperature grid |
| `L` | size of the confinement region |
| `RUN_PARAMETER_STUDY` | `True` for all parameter sets, `False` for the baseline only |
| `PARAMETER_SETS` | list of $(a, b, \gamma)$ sets |

## Output

The `results/` directory contains:

| File | Contents |
|---|---|
| `raw.csv` | every quantity for every run |
| `summary.csv` | mean, standard deviation and SEM per (set, $T$, method) |
| `E.png`, `F.png`, `S.png`, `Cv.png`, `P.png` | quantity versus $T$ with error bars, one panel per parameter set |

The console prints a summary table with `⟨E⟩ ± σ`, `F ± σ`, `S ± σ`, `C_V ± σ`, `P ± σ` and the ESS for both methods. Error bars in the plots show the standard deviation over 10 runs.

## Key findings

- Both methods agree within statistical error across all parameter sets.
- At low temperatures ($T \approx 0.5$–$1.5$) CMC suffers from large variance and bias: its ESS is only about 10–200 out of 100,000, while IS keeps the ESS above 90,000 there. IS errors are one to two orders of magnitude smaller.
- At $T = 0.5$, $a = 1$ the results give $\langle E \rangle \approx 3T/2$ and $C_V \approx 3$, as expected for six quadratic degrees of freedom of a harmonic trap.
- $C_V$ decreases with temperature because the region is bounded by $L$. The decrease is faster for a weaker trap ($a = 0.7$).
- Pressure is essentially zero at low $T$, since the particles stay near the trap center, and grows at high $T$. A weaker trap gives a higher pressure.
- Negative entropy at low $T$ is expected: the entropy of a classical system with a continuous phase space is defined up to an additive constant.

## Validation

For $b = 0$ the partition function is known analytically:

$$Z = \left[\frac{1}{2}\sqrt{\frac{\pi T}{a}}\,\mathrm{erf}\!\left(L\sqrt{\frac{a}{T}}\right)\right]^6$$

IS results for $F$, $\langle E \rangle$ and $P$ agree with this to 3–4 significant digits. For $b > 0$, consistency of the estimators was checked through derivatives of $\ln Z$ ($\langle E \rangle = T^2 \partial_T \ln Z$, $S = -\partial_T F$, $C_V = \partial_T \langle E \rangle$) to within about 0.1–0.2 %.
